조건으로 새 찾기

분포 범위, 분류군(목·과·속), 대표 서식 환경, 먹이 구성을 조합해 출처가 확인된 종(species)을 찾아보세요.

1. 분포 범위 · 이름 우선 기준

전체 분류군을 표시하며 검증된 한국어 이름을 먼저 보여줍니다. 국내 기록·분포 확인은 출처의 야생 기록·분포 유무이며 모두 텃새라는 뜻이 아닙니다.

목·과·속 단위로 범위를 좁힙니다(종·아종 제외). 비워두면 선택한 분포 범위의 전체 조류를 대상으로 조회합니다.

AVONET 자료의 종별 대표 서식 환경(1개)과 일치하는 종을 찾습니다.

4. 먹이 구성 (EltonTraits · 복수 선택 가능)

복수 선택 시 선택한 먹이가 모두 0%보다 큰 종(AND 조건)만 찾으며, 결과는 선택한 먹이 비율의 합계가 높은 순으로 정렬됩니다(가나다·알파벳순 아님). 먹이를 선택하지 않으면 이름순으로 정렬되며, 확실성 A·B·C 자료만 사용합니다.

먹이 분류 안내

‘곤충’은 자료의 무척추동물 범주로 다른 무척추동물도 포함합니다. 고기는 온혈동물·변온동물·기타 고기로 나누며 물고기와 사체는 별도입니다.

분포 범위, 분류군, 서식 환경, 먹이 조건을 선택하고 ‘조건으로 새 찾기’를 눌러 조회하세요.

모든 조회 결과는 활성 분류 체계(AviList)와 직접 연결된 형질 자료(AVONET, EltonTraits)만을 근거로 종(species) 단위로 표시합니다.
