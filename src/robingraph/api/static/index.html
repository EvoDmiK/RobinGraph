이 화면은 수동 검증용 테스트 UI입니다. 분류·관찰 응답은 조회 결과를 정해진 규칙으로 표시합니다. 근거 문서 응답은 Gemini API가 설정된 경우 조회된 근거로 답변을 생성할 수 있습니다. 근거가 없으면 답변을 보류하고, 생성이나 검증에 실패하면 검색 결과만 보여줍니다.

대화 기록은 로그인이나 별도 저장 없이 이 창에서만 유지되며, 새로고침하거나 "대화 지우기"를 누르면 사라집니다.
