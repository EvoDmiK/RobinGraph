# 한국어 PMC 문헌 검색 API 검증 — 2026-09-30

## 대상과 범위

로컬 TEST Neo4j와 PMC9946348 한 편을 사용했다. 브라우저 조작 없이 실제
`/health`, `/chat`, 정적 파일, `/v1/search`, `/v1/chat`을 HTTP로 호출했다.
`127.0.0.1:8002`의 서버는 현재 코드로 새로 실행했다. 운영 배포는 수행하지 않았다.
API의 `fixture_only: true`는 실험용 코퍼스를 의미한다.

## 변경 전

같은 의미의 한국어/영어 질문 5쌍을 fulltext로 조회했다.
영어는 모두 PMC 결과 3개를 찾았다. 한국어는 4개 질문에 결과가 없었고,
철새·물새 질문은 PMC 대신 합성 fixture 결과 2개를 반환했다.
기존 fulltext 검색은 한국어 질문을 영어 본문에 그대로 매칭하고 있었다.

## 변경

- 기존 Gemini 어댑터로 한국어 질문의 영어 검색어를 생성해 원래 검색어에 추가했다.
  한국어 fulltext에만 적용하고 영어 질문 및 auto/hybrid에는 추가 호출을 하지 않는다.
- 조류 생태 문헌이라는 문맥을 명시해 `조류`를 algae/tide로 잘못 해석하지 않도록 했다.
  질문에 있는 개념만 번역하고 답변이나 새로운 사실을 검색어에 추가하지 않도록 요청한다.
- 영어 검색어는 20단어·300자 이내의 제한된 문자 형식으로 검증하고,
  기존 Lucene 이스케이프를 거친다. 실패 시 원래 질문으로 조회하고 경고를 표시한다.
- 답변은 질문의 언어로 생성하고, 기존 검색 근거 ID 검증을 그대로 적용한다.
- 실제 호출에서 발생한 Gemini HTTP 503에 대해 1초 뒤 한 번만 재시도한다.
  지속적인 오류는 검색/생성 fallback으로 처리하며 키나 제공자 오류 본문을 노출하지 않는다.
- 새 패키지는 추가하지 않았다.

## 모델 비교와 최종 결과

`gemini-3.8-flash`에서 검색어 변환/답변 호출 실패가 반복됐다. 별도 진단에서는
HTTP 503을 확인했다. 재시도 추가 후 5개 질문 중 한국어 생성 답변 성공은 1개였다.
동일 키의 모델 목록에서 지원을 확인한 `gemini-3.5-flash-lite`를 TEST 서버의
환경 변수로 지정해 비교했다. `.env`와 코드의 기본 모델은 바꾸지 않았다.

| 질문 | PMC 인용이 있는 한국어 응답 | 응답 시간 | 내용 확인 |
|---|---|---:|---|
| 로스앤젤레스의 기후·토지 이용 변화와 조류 다양성 | 성공 | 3.08초 | 건조화·도시화의 복합 영향을 설명 |
| 로스앤젤레스와 센트럴밸리의 차이 | 성공 | 3.03초 | 감소와 상대적 안정의 차이를 설명 |
| 기후와 토지 이용의 반대 영향 | 성공 | 2.84초 | 서로 상쇄하는 영향을 설명 |
| 과거 조사와 최근 조사 비교 | 성공 | 2.42초 | 역사적 야장과 조사 지점을 설명; 비교 방법 전체를 다 설명하지는 않음 |
| 철새·물새에 적용 가능 여부 | 성공 | 2.75초 | 현재 검색된 근거로 확인할 수 없다고 응답 |

모든 응답에서 인용 ID가 검색 결과에 속하고, 인용 출처의 PMC URL·문단 위치·
CC BY 4.0 표기가 존재하는지 검증했다. 이는 인용 연결 검증이며 각 주장 전체의
사실성을 자동으로 보증하는 검사는 아니다.

철새·물새 질문은 상위 3개 중 PMC 결과가 1개뿐이었고, 해당 응답은 논문에 있는
중요한 연구 한계 문단(`p017`)을 찾지 못했다. 이 소규모 검증은 한국어 검색이
가능해졌음을 보여주지만 검색 완전성이나 모델의 장기 안정성을 보증하지 않는다.

## 재현

```sh
ROBINGRAPH_GEMINI_MODEL=gemini-3.5-flash-lite .venv/bin/robingraph serve-neo4j --host 127.0.0.1 --port 8002
```

```json
{
  "question": "로스앤젤레스에서 기후 변화와 토지 이용 변화가 조류 다양성에 어떤 영향을 줬어?",
  "intent": "evidence",
  "filters": {"kind": "evidence", "limit": 3}
}
```

한국어 fulltext에는 검색어 변환 호출이 한 번 더 필요하다. 결과가 있으면 답변
생성 호출도 수행한다. 503 재시도는 최대 한 번씩 추가되므로 실패 시 지연이 늘 수 있다.

전체 Python 테스트: 420개 실행, 성공(31개 건너뜀). 변환 스키마와 출력 경계,
한국어/영어/hybrid 경로, 변환 실패의 원문 검색 fallback, 503 재시도 상한을 검증했다.
