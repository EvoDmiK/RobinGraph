# 국명 408종·형질 공백 503종·평가 미연결 447종 원자료 재검토

## 요청 배경과 완료 기준

사용자는 한국어명이 있는데 영어로만 표시되는 후보 408종에 이어, 형질 공백 503종과 보전 평가 미연결 447종도 함께 처리하도록 요청했다. 특정 종의 예외만 추가하거나, 기존 자료에서 값이 없다는 이유로 검토를 중단하지 않는 것이 이번 작업의 핵심이다.

세 집합은 중복을 포함하며 고유 종 수는 1,043종이다. 개별 집합의 합계를 전체 고유 종 수로 표현하지 않는다. 작업 시작 시점의 대상과 식별자는 [`2026-10-09-resolution-baseline.json`](../verification/assets/2026-10-09-resolution-baseline.json)에 고정했다. 이후 데이터가 개선되어도 처음 요청한 종을 분모에서 빼지 않는다.

완료 검증에서는 다음을 구분한다.

- 원자료에서 후보를 발견한 것과 실제 서비스에서 그 자료를 반환하는 것.
- 종 전체 자료, 종 안의 아종군 자료, 연구 표본 평균, 문헌 범위값 평균, 저자의 추정값.
- 공식 평가의 실제 발표와 다음 평가에 대한 권고.
- 원자료의 조사·발행 연도와 개별 IUCN 평가 연도.
- 실제 DB를 읽는 전체 런타임 검증, 실제 HTTP 요청, 브라우저 확인, 모의 객체를 사용하는 단위 테스트.

## 협업과 역할

- 국명 담당: 408종의 산림청·CITES·eBird·Avibase 원문 대조, 국명 충돌 및 분류 범위 검토, 검증된 이름 목록과 검색 회귀 검증.
- 형질 담당: AVONET의 추가 시트와 eBird 아종군 관계, BIRDBASE 등 대체 공개 데이터 조사, 출처가 보존되는 결측 보완 구현.
- 보전 평가 담당: 447종의 원문 체크리스트, 명명자 표기 차이, 분류 결정 기록, 발표 일정, 대체 자료와 검증 조건.
- 통합 담당: 공통 UI의 범위·추정값 표시, 전체 대상 비교 도구, 배포 및 실제 환경 검증, 작업 문서 통합.

## 확인한 원인과 수정 원칙

### 형질

기존 AVONET 수집은 `AVONET1_BirdLife` 시트 중심이었다. 동일한 고정 원본에는 저자가 eBird 분류로 집계한 `AVONET2_eBird`도 있다. 원본의 Avibase 개념 ID와 현재 종의 ID를 정확히 대응시키면 이름만 비교할 때 놓친 자료를 회복할 수 있다. 추출 파일은 원본 시트·행·필드·해시·출처·라이선스와 저자 추정 여부를 보존한다.

공식 eBird 분류의 `issf → report_as`는 아종군이 어느 종 안에 포함되는지를 보여준다. 이것을 종 전체의 평균과 같다고 해석하지 않는다. 여러 아종군 자료가 있으면 첫 번째 것을 종 대표값으로 고르거나 임의 평균하지 않는다. 별도의 종 전체 자료가 있으면 그 자료를 우선한다.

BIRDBASE 문헌 체중의 `Average Mass`는 항상 단순한 전체 최소·최대 중간값이 아니다. 암컷·수컷·성별 미구분 범위의 기재값을 이용한 문헌 범위 평균이므로, 개체를 측정해 계산한 종 평균과 구분해야 한다. 원래 범위 항목을 출처와 함께 보존한다.

### 보전 평가

빈 BirdLife SIS 링크나 AviList의 NE는 단독으로 해당 종이 실제로 평가되지 않았음을 증명하지 않는다. 반대로 학명이 같다는 이유만으로 다른 명명자·분류 범위의 LC를 자동 승계할 수도 없다.

참고 평가의 명명자 정규화는 이니셜 생략 등 허용한 표기 차이만 다룬다. 저자 성, 저자 순서, 연도, 명명자 괄호 등 다른 정체성 단서를 무작정 지우지 않는다. 주 평가 연결의 검증 조건을 완화하는 대신, 참고 자료의 근거와 원래 미연결 상태를 별도로 보존한다.

BirdLife 2026.1 변경 결정 문서는 출시된 개별 IUCN 평가와 구별한다. 공식 포럼에 다음 릴리스에 제출할 권고라고 명시되고 출시가 미래로 안내된 항목은 현재 공식 등급으로 올리지 않는다.

### 국명

Wikidata의 한국어 문자열 존재만으로 새 국명을 확정하지 않는다. 독립 출처에서 정확한 학명 또는 분류 개념을 대조한다. 기존 한국어 표준 목록과 검증된 기관 자료를 우선하고, 다른 종과 국명이 충돌하거나 이전 분류의 범위를 가리키는 경우는 자동 덮어쓰지 않는다. Avibase를 사용한 이름은 해당 출처의 참고 국명이지 국내 표준 국명이라고 표시하지 않는다.

## 변경 전후 동작

형질 보완은 빈 필드를 채우며 기존 종 전체 자료를 덮어쓰지 않는다. 아종군만 있는 경우에는 앞·뒷면 기본 항목과 비교표에 범위를 표시한다. 여러 아종군이 있으면 카드에는 자료의 개수를 표시하고, 각 범위와 실제 값은 답변 출처에 모두 보존한다. 아종군 범주를 종 전체의 서식 환경 아이콘이나 먹이 비교 점수로 사용하지 않는다.

카드의 추정값 표시뿐 아니라 답변 출처에 원래 추정 근거와 참조 종 설명도 출력한다. 출처 설명은 HTML로 해석하지 않고 텍스트로 표시한다.

## 교차 검토에서 추가 수정한 사항

1. 생활 방식의 도넛 대체 표시에도 아종군 범위를 유지했다.
2. 비교표의 보이는 체중 값에 문헌 범위 평균·연구 표본 평균을 구분하고, 비교표 출처에도 설명·원래 범위·분류 연결을 보존했다.
3. 아종군 연결의 근거가 되는 공식 eBird 링크를 출처에 표시했다.
4. AVONET `Total.individuals`를 모든 형질의 표본수로 표시하지 않게 했다. 형태측정 총개체수는 개별 형질 유효 표본수나 별도 체중 문헌의 표본수가 아니므로 `source_morphology_sample_size`로 분리했다.
5. 원문 설명을 `textContent`로 출력해 자료 문자열이 HTML로 실행되지 않게 했다.
