# IUCN 배지 복구 · 운영 승인 대기

## 요청과 원인

사용자는 ‘평가 범위 확인 필요’와 ‘출처 범위별 설명’이라는 내부 검토 표현을 지적했으나, 이전 수정은 등급 미연결 배지를 통째로 숨겼다. 사용자가 배지 삭제를 요청한 것이 아니므로 잘못된 처리였다. 추가로 사용자는 직접 괜찮다고 승인하기 전까지 운영 배포를 금지했다. 이 지시는 과거의 포괄적인 운영 배포 허용보다 우선한다.

## 수정

- `chat.js`: 본문 요약 배지와 카드 배지의 hidden 조건을 되돌렸다. 실제 등급이 연결된 LC 등 배지는 그대로이며, 등급 연결 정보가 없는 경우에도 `IUCN 적색목록 · 등급 정보 없음` 배지를 표시한다.
- 평가 코드·출처·검증 상태·원자료는 바꾸지 않는다. 미연결을 LC나 실제 NE로 바꾸지 않고 중립색을 유지한다. 평가 연결 사유는 답변 출처에서 확인한다.
- 외관·생활 설명을 본문에 표시하는 변경과 아종군 형질 보충 제거는 유지한다. 과거 내부 검토 표현이나 범위별 설명 토글을 복구하지 않는다.
- `AGENTS.md`에 명시적 운영 승인 필수, TEST까지만 작업, 무승인 운영 배포·컨테이너 재시작·DB 변경·롤백 금지 정책을 기록했다. 일반 ‘진행’ 지시를 운영 승인으로 간주하지 않는다.

## 검증

프런트 전체292개 통과, 실패0·건너뛰기0. 기대 문구가 바뀐 기존 테스트1개를 새 계약에 맞게 수정했다. 독립 협업 검토에서도 데이터/보전 검증기/등급색상 규칙이 바뀌지 않았고 본문·카드 두 경로 모두 복구됨을 확인했다. 협업자는 읽기 전용 검토만 수행했다. 백엔드 변경은 없으므로 Python/DB 전체 재검증을 새로 실행하지 않았다. `graphify update .` AST 갱신을 실행했다.
