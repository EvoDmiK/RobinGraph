# Writer의 Obsidian 직접 작성 역할 명확화 — 2026-10-17

## 요청과 배경

사용자가 Writer Agent에게 Obsidian 쓰기도 맡기도록 지시했다. 기존 AGENTS.md에는 Obsidian 역할이 이미 있었지만 직전 RG-406 작업은 로컬 초안만 배정되었다. 앞으로 기본 문서 완료 범위가 실제 Obsidian 저장·재조회까지임을 명시했다.

## 변경과 전파

AGENTS.md Writer 절에 사용자 지시일과 기본 책임(로컬 기록·Obsidian MCP 생성/수정·관련 백로그·저장 재조회)을 추가했다. 별도 로컬 전용 지시 예외, 근거 기반 상태 변경, 무관한 본문 보존, 한 작업 한 명 쓰기를 명시했다. dev-codex/dev-claude/main/main-2 네 워크트리에 기존 지침을 보존하여 동일 문구를 추가하고 존재 여부를 확인했다.

Orca 기존 Writer 터미널에 지침 재독과 최신 RG-406 고급 옵션 TEST 배포 기록의 백로그 연결 작업을 전달했다. 과거 로컬 초안으로 최신 상세 노트를 덮어쓰지 않도록 최신 증거 경로·이미지·자료 한계를 제공했다. 기존 상세 Obsidian 두 문서는 이미 총괄이 작성했으므로 중복 생성 대신 백로그 최소 갱신과 재조회를 맡겼다. 총괄은 같은 대상에 동시에 쓰지 않는다.

## 검증과 경계

네 워크트리 추가 문구 확인, git diff --check 통과. 역할 문서 변경이므로 앱 테스트·graphify 코드 갱신·배포·DB 쓰기는 해당하지 않는다. commit/push/병합 없음. Writer에 작업 전달 완료와 실제 Obsidian 후속 작업 완료를 구분한다. 후속 Obsidian 변경 결과는 Writer가 보고하며 이 시점에는 그 작업 완료를 추정하지 않는다.
