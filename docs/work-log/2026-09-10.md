## 남은 운영 항목

정식 reference/AVONET import artifact는 제한된 NAS에서 workbook 전체 파싱을
반복하지 않도록 비활성으로 유지한다. reference 자동 갱신이 필요하면 byte-range
단계 수집 또는 같은 방식의 외부 스트리밍 batch 공급을 정식 운영 경로로 승격한다.

## NAS 배포 패키지

API 이미지에 `config/`, `n8n/`, `scripts/`를 포함하고 `compose.nas.yml`에
일회성 `nas-tools` profile을 추가했다. 상시 API와 도구 secret을 `.env.nas`와
`.env.nas.ingest`로 분리하며, n8n workflow 백업과 AVONET 원본 cache는 별도
Docker volume에 보존한다.

`scripts/deploy_nas.sh`는 외부 network·필수 환경값·Compose 구성을 사전 점검하고,
API build/deploy/health 확인, inactive n8n workflow 배포, AVONET 검증·적재를
각각 명시적인 명령으로 제공한다. 기존 Neo4j/n8n/NPM 컨테이너는 이 Compose가
소유하거나 재생성하지 않는다.
