# 카드 비율 자료 영역 중앙 정렬·생활 방식 요약·기존 평가 뱃지 표시

## 요청과 목표

2026-10-09 사용자가 까치 카드 뒷면을 제시하고 먹이 구성·먹이 활동 위치 아래의 상자와 내용을 중앙 정렬하도록 요청했다. 먹이 활동 위치는 먹이 유형처럼 짧게 설명하고 다음 줄에는 `비율 자료 없음`만 표시하도록 요청했다. 이어 평가 연도가 다른 종도 보유한 평가 자료로 뱃지를 만들라고 요청했다. 두 요청을 같은 최종 TEST 배포에 반영했다.

## 확인한 원인

- 점선 상자는 자체 `margin: 0 auto`가 있었지만 `.message p` 문단 스타일의 우선순위가 더 높아 좌우 자동 여백이 적용되지 않았다. 제목은 가운데이고 상자만 왼쪽으로 치우쳤다.
- 정성 자료 대체 표시가 긴 주 생활 방식 전체와 별도의 범위 설명까지 상자에 담아 줄바꿈·말줄임이 많았다.
- 앞선 보전 등급 작업은 참고평가를 별도 줄로 제공하면서 주 뱃지는 `평가 범위 확인 필요`로 유지했다. 평가 연도가 다르다는 이유로 원자료를 삭제한 것은 아니었지만, 뱃지에서 보유 평가 등급을 바로 볼 수 없었다.

## 변경 전후와 구현

### 비율 자료 영역

`src/robingraph/api/static/styles.css`에서 분포 열 안의 대체 상자 선택자를 구체화해 대화 문단 스타일보다 우선하도록 했다. 상자 좌우 자동 여백, 내부 가로·세로 중앙 정렬, 기존 100px 높이와 두 열 구조를 유지한다.

`src/robingraph/api/static/chat.js`에서 주 생활 방식의 첫 구절을 요약으로 사용한다. 가운데점·세미콜론·줄바꿈으로 나뉜 첫 부분을 쓰며, 추정값 표시가 있으면 보존한다. 특정 종 이름에 대한 조건은 없다.

까치 예시:

- 먹이 구성: `먹이 유형 · 잡식` / `비율 자료 없음`
- 먹이 활동 위치: `생활 방식 · 땅에서 먹이 탐색` / `비율 자료 없음`

전체 주 생활 방식은 기존 상세 정보에 유지한다. 이 값이 실제 먹이 활동 층의 비율이라는 뜻은 아니다. 전체 문구와 범위 설명은 상자의 title에도 보존하고, 상자 본문에서 긴 추가 설명을 제거했다. 비율이 없는 상태에서 가짜 도넛이나 백분율을 생성하지 않는다. 자료가 실제 존재하는 도넛 표시는 변경하지 않았다.

### 보전 등급 뱃지

유효한 참고평가가 있으면 뱃지에 그 등급·평가 연도·참고 구분을 표시한다. 큰부리까마귀는 `관심대상 (LC) · 2024 평가 · 참고`가 된다. 이미 연결된 평가에도 유효한 평가 연도를 함께 표시한다. 연도가 없는 유효 참고평가는 등급과 참고 구분을 표시한다.

현재 분류 범위와 일치 미확인이라는 기존 안내와 출처·인용은 유지한다. 참고평가를 현재 종의 확정 등급으로 승격하거나 API 주 등급을 덮어쓰지 않는다. 미확인 카드의 중립색도 유지한다. 참고평가가 없는 종은 기존 확인 필요 뱃지를 유지한다. 연도가 오래되었다는 이유만으로 유효 평가를 배제하지 않는다.

프런트엔드의 기존 출처·식별자 검증을 통과한 참고평가만 사용한다. 테스트의 기대 문구를 새 계약에 맞춰 변경했다.

- Node 프런트엔드 전체 279개 통과, 실패 0, 건너뜀 0. 두 구현 단계에서 실행했고 최종 뱃지 변경 후에도 통과했다.

- 코드 변경 후 `graphify update .` 실행. SQL 파서 부재에 따른 기존 제외는 이 UI 수정과 무관하다.
