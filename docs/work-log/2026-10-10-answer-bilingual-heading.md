# 답변 제목의 국명·영문명 병기

## 요청 배경과 목표

사용자는 청둥오리 답변 화면에서 국명 옆에 카드처럼 작은 영문명을 표시하고, 오른쪽 위 빈 공간에 들어갈 내용을 추천해 달라고 요청했다. 국명·영문명 병기는 구현하며, 빈 공간은 추천 범위로 두었다.

## 원인과 변경 전후

`buildSpeciesAnswer`는 `speciesLabel(profile.taxon)`만 제목에 넣었다. 카드는 이미 검토된 국명 옆에 별도 영문명을 표시하므로 같은 프로필에서도 화면별 이름 구성이 달랐다. 답변 제목에도 기존 프로필의 `english_name`을 사용한다. 국명이 있고 영문명이 비어 있지 않으며 서로 다를 때만 작은 영문명을 덧붙인다. 기계 번역 국명은 기존 정책대로 채택하지 않는다. 영어 이름만 있는 종이나 동일한 이름을 가진 종은 제목을 중복하지 않는다.

영문명은 제목 글씨의 72% 크기, 일반 굵기, 보조 색상이며 `lang="en"`을 지정한다. 제목은 기준선을 맞춘 flex 배치와 줄바꿈을 사용한다. 긴 문자열은 화면을 넘지 않고 HTML이 아닌 일반 텍스트로 표시한다. 학명은 기존 기본 정보에 유지한다.

## 변경 파일

- `src/robingraph/api/static/chat.js`: 답변 제목의 보조 영문명 생성과 빈 값·기계 번역·중복 방지.
- `src/robingraph/api/static/styles.css`: 제목 기준선, 작은 보조 글씨, 긴 이름 줄바꿈.
- `tests/frontend/chat_ui.test.js`: 기존 답변 구조 검사의 제목 클래스 기대값을 새 구조에 맞춤.
- `docs/verification/assets/2026-10-10-answer-bilingual-heading.json`: 실제 Chrome 16설정 검증 결과.

## 검증 방법과 실제 결과

`node --test tests/frontend/*.test.js`: 최종 298개 통과, 실패 0, 건너뜀 0. 첫 실행은 기존 레이아웃 검사가 제목의 빈 클래스를 기대해 1개 실패했다. 제품의 새 제목 클래스를 기대하도록 해당 구조 검사를 수정한 뒤 전체가 통과했다.

실제 TEST API `/v1/taxa/profile?name=Anas%20platyrhynchos`에서 받은 프로필을 사용하고, 공개 TEST 페이지의 JS/CSS만 로컬 수정본으로 가로채 실제 Chrome에서 렌더링했다. 320·390·768·1280px 각각 실제 프로필, 긴 특수문자 포함 이름, 국명 없음, 기계 번역 국명의 4사례를 확인하여 총 16개 통과했다. 실제 프로필 4개 설정과 이를 수정한 모의 예외 자료 12개 설정을 구분한다. 영문명의 작은 크기·텍스트 일치·영문 언어 태그, 제목의 이미지 주입 없음, 가로 넘침 없음, 페이지 오류 없음, 영어 대체 시 보조 이름 없음이 통과했다. 390px 스크린샷도 직접 확인했다.

11,131종 전체 HTTP 검증이나 물리 모바일 기기·Safari 검증은 수행하지 않았다. 새 모델 호출·DB 변경이 없는 프런트엔드 표시 변경이므로 백엔드 전체 테스트와 DB 이관은 해당하지 않는다. `graphify update .`의 AST 갱신도 완료했다. SQL 추출 의존성 및 커뮤니티 이름 경고는 기존 그래프 도구 한계로 남아 있다.

## 빈 공간 제안과 구현 경계

오른쪽 위에는 라이선스가 확인된 대표 사진과 `도감 카드 보기` 동작을 묶은 작은 영역을 추천했다. 종의 모습과 카드 진입을 동시에 제공할 수 있다. 사진이 없는 종의 대체 표시와 모바일 배치를 함께 설계해야 한다. 사용자는 이 부분을 추천해 달라고 했으므로 이번에는 사진 영역을 구현하지 않았다.

## 배포·Git과 후속 사항

수정은 `dev-codex`에 기록한다. 이번 요청에는 운영 배포 지시가 없어 TEST·Production 서버에 배포하거나 main/dev에 병합하지 않았다. 공개 서버에서 수정이 보이는 상태로 주장하지 않는다. 수정 커밋은 이 문서와 검증 JSON을 포함하며, Git 로그에서 확인할 수 있다. 다음 배포 때 정적 자산 전달과 실제 답변 화면을 다시 확인한다. 빈 공간 사진 영역은 사용자 선택 후 구현한다.
