# 전체 활성 종 데이터·국명·검색 전수 점검

## 요청과 이전 완료 보고 정정

사용자가 까치·박새 등 일부 종의 검색·뱃지만 고치지 말고 모든 종의 자료 연결과 표시를 검증하라고 요청했다. 박새 카드의 체중·먹이·서식 환경·평가 자료가 비어 있는데 검색 복구를 완료로 설명했던 것이 문제였다. 추가로 한국어 이름이 원자료에 있는데 영어로만 나오는 종도 전수 조사하도록 요청했다.

이번 작업은 이름 검색, 국명 표시, 형질 저장·연결, 평가 연결, 뱃지 표시를 구분한다. 검색 성공은 자료 완전성을 보장하지 않으며, 미연결 자료를 임의로 채우거나 현행 종에 다른 분류 범위의 평균값을 상속하지 않는다.

## 실제 조사 범위와 결과

EltonTraits 원자료 9,993행과 AVONET 11,009행도 확인했다. PostgreSQL 원자료 행 누락은 두 자료 모두 0, 비교 가능한 형질 값 불일치도 0이었다. 정확 학명으로 연결되는 행은 각각 7,752와 9,879이며, 미연결 원자료 행은 각각 2,241과 1,130이다. 이 수는 원자료 행 수이며, 현재 종의 자료 공백 수와 같지 않다.

- 연결된 공개 평가 7,507종, AviList 등급만 있는 종 2,816종, 연결 검토 대상 807종, 까치 별도 표시 1종.

### 한국어 원자료·실제 표시

전체 활성 종의 source-preferred 영어 이름과 DB 국명을 추출했다. 현재 자료의 영어명은 대소문자 정규화 후 중복 0이다. 기존 검토 국명 646개는 표시 함수에서 모두 유지되며 영문명 불일치로 숨겨진 항목 0이었다.

한국조류학회 598개 원자료, IOC 국명자료, 서울대공원 자료의 전수 대조에서 설명되지 않은 누락은 없었다. 다만 검토 목록 밖 DB 국명은 기존 정책상 숨겨져 있었다. 자동 번역·타종 오연결을 막기 위한 기존 정책이므로 무조건 복원하지 않았다.

추가로 국가법령정보센터의 국명·학명 표 27행을 검토하여 정확히 일치하는 19종을 보강했다. 이집트기러기·붉은홍관조·평화비둘기·호주까치·흰가슴까마귀 등이 포함된다. 4행은 기존 검토 이름을 유지하고 4행은 정확한 학명 연결이 없어 보류했다. 법령의 생태계 위해성 분류나 IUCN 등급을 가져온 것은 아니며 이름 사실만 사용했다.

확장 후 전체 11,131종의 표시 함수 대조: 국명 665종 표시, 검토 국명 표시 결함 0, 영어 우선 10,466종. 추가 근거 검토가 필요한 DB 국명 408종을 전부 목록화했다. 독립 출처 추가 확인 필요 390, 타종의 검토 국명과 충돌 12, 비한국어 값 6이다. 408종을 전부 오기 또는 검증된 국명이라고 단정하지 않는다.

국명 상세 원문·SHA·행별 판단은 [별도 국명 작업 문서](2026-10-09-korean-name-full-source-audit.md)에 기록했다.

## 공통 원인과 수정

박새의 현행 AviList Parus cinereus는 이전 minor 집단을 포함하는 분류 범위다. 형질 원자료의 과거 Parus major 행을 그대로 옮기면 범위가 다른 종의 값을 현행 종 평균으로 표시하게 된다. 현재 승인된 형질 crosswalk에 박새 대상 행이 없다는 것이 공백의 원인이다. 원자료가 DB에 덜 저장된 문제는 아니었다.

추가로 비한국어 검색은 학명만 조회하고 source-preferred 영어명을 조회하지 않는 공통 결함을 발견했다. `lineage_for_english_name`과 CLI fallback을 추가하여 학명 조회가 없을 때 정확한 영어 이름을 조회한다. 활성 분류판·종 rank·자료 정책·데이터셋과 반환된 종 ID를 검증하며, 여러 종에 해당하면 임의 선택하지 않는다. API matched_by에 english_name을 추가했다.

변경 파일: taxonomy_lineage_neo4j.py, taxonomy_lineage.py, cli.py, api/app.py, species_ko_names.json 및 관련 테스트. 재현 가능한 감사 도구 audit_active_species_runtime.py, audit_active_species_names.py, audit_korean_name_sources.py를 저장했다.

## 자동 테스트

계통 저장소 31개, CLI 8개, API 42개, 종 프로필 24개, 국명 표시 6개: 총 111개 통과. 실패·건너뜀 0. CLI 최초 실행은 Python 3.14 의존성 DeprecationWarning이 stderr 예상과 달라 실패했고 경고 필터를 지정해 재실행했다. 실질 검색 실패를 무시한 것이 아니다.

전체 Python 테스트와 외부 API 통합 테스트 전체를 돌린 것은 아니다. 프런트엔드 소스를 바꾸지 않아 Node 단위 전체는 반복하지 않았고, 대신 전종 실제 보전 응답의 표시 함수 검사를 실행했다. git diff --check 통과, graphify update 실행.

## 해결되지 않은 범위

형질 공백 503종과 참고 평가 연결 근거가 없는 447종은 아직 남아 있다. 이 항목들은 이번 감사로 발견·분류한 미해결 목록이지 수정 완료 목록이 아니다. 안전한 분할·병합 근거 또는 종별 원자료가 추가로 필요하다. 국명 검토 대기 408종도 독립 출처와 정확한 종 대응을 확인해야 한다.

이번 수정으로 검색·국명 범위는 개선되지만 박새의 형질과 평가 근거가 새로 생기는 것은 아니다. 그 공백이 있는 상태를 데이터 완성으로 보고하지 않는다.
