# 전체 활성 종의 국명 표시 감사와 기관 근거 국명 보강

## 요청 배경과 범위

사용자는 박새·까치 같은 신고된 종만 수정하는 대응을 중단하고, 한국어 이름이 존재하지만 영어로만 표시되는 종을 전체 조사하도록 요청했다. 이 문서는 국명 자료·표시 경로의 조사 결과다. 형질과 보전 등급의 검증은 별도 전체 데이터 감사에서 다룬다.

## 확인한 원인

`with_korean_display_name`은 검토 국명 파일의 종 ID·학명·영문명이 모두 일치할 때만 국명을 반환한다. 파일 밖의 Neo4j 국명은 community-sourced라 해도 지운다. 이는 2026-10-06 자동 번역을 제거하고 Wikidata 이름도 별도 근거가 있을 때만 채택하기로 한 표시 정책이다. 따라서 DB에 한글이 있다는 사실만으로 누락 오류라 단정하거나 모든 이름을 복원하면 안 된다.

최신 TEST DB에서 추출한 활성 AviList v2025b 전체 11,131종을 대조했다. 기존 검토 국명 646종은 모두 ID·학명·영문명과 일치하고 표시된다. 영문명 불일치로 이 646개 국명이 버려지는 경우는 0이었다. 검토 목록 밖에서 DB 국명이 있지만 숨겨지는 종은 보강 전 413종이었다. 추출에는 여러 Wikidata 스냅샷의 같은 이름이 포함되어 있어 레코드 수를 종 수로 합산하지 않았다.

## 기존 원자료 전수 대조

- 한국조류학회 2025 목록 598행: 정확학명 593, 검토된 속 이동 3, 활성 종에 정확히 대응하지 않는 2. Anas carolinensis와 Saxicola stejnegeri는 임의 연결하지 않았다.
- IOC v15.2 다국어 추출: 11,227종 행 중 한국어 값 567행. 같은 국명이 검토되어 표시되는 525, 기존 우선 출처 이름 유지 31, 다른 종에 이미 부여된 국명 9, 활성 종 불일치 2.
- 서울대공원 45행: 원문과 같은 이름 25, 기존 우선 출처 유지 9, 정확학명 없음 9, 다른 종 국명 충돌 1, 기존 검토에서 철자 문제가 지적된 1. 마지막 건은 Vultur gryphus의 '안데슨콘도르'이며 이를 자동 채택하지 않았다.

기존 세 원자료에서 이유 없이 빠뜨린 확정 국명은 발견하지 않았다. 이것은 모든 한국어 출판물에 추가 국명이 없다는 의미가 아니다.

## 추가 출처 조사와 실제 변경

새 기관 자료로 국가법령정보센터의 [별표 7의2 유입주의 생물](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=200201&flSeq=148704025)의 **국명·학명 대응 표**를 확인했다. 법적 지정 상태를 앱에 적용한 작업이 아니며, 이 PDF를 최신 법규라고 주장하지 않는다. 고정 파일에서 확인한 이름의 근거로만 사용한다. 원문 전체를 저장소에 재배포하지 않고 개별 국명·학명 사실과 출처 URL·쪽·행·SHA-256을 기록했다.

원본 SHA-256: `2a0538adbdd042b4328cd96f04df57e7c85598c15983986b7a9afe751a22eb12`.
PDF 2~3쪽을 내려받아 텍스트 추출하고 두 페이지를 이미지로 렌더링해 원문 표와 직접 대조했다. 웹 도구의 PDF 스크린샷은 시간 초과로 실패해 로컬 PyMuPDF 렌더링을 사용했다.

조류 27행 전체를 검토하여 **19종을 추가**했다. 일본꿩, 붉은수염직박구리, 흰죽지비둘기, 숲찌르레기, 붉은홍관조, 평화비둘기, 회색뿔찌르레기, 이집트기러기, 붉은눈검은찌르레기, 검은턱웃음지빠귀, 갈색머리검은피리새, 큰타이런트새, 자색물닭, 붉은꽁지직박구리, 호주까치, 긴꼬리단풍조, 붉은부리베짜는새, 아프리카염주비둘기, 흰가슴까마귀다.

나머지 8행은 기존 검토 국명 우선 유지 4, 정확한 활성 학명 부재 4다. 예를 들어 Acridotheres javanicus의 기존 자바뿔찌르레기를 자바찌르레기로 덮어쓰지 않는다. Garrulax나 Streptopelia의 속 이동은 별도 근거 없이 추정하지 않는다.

`species_ko_names.json`의 검토 이름은 646→665종이 됐다. 각 항목의 status는 기존 `source-reference`이고 활성 종 ID·학명·영문명 검증을 그대로 거친다. 새 번역·부분 문자열 추정·DB 원본 이름 덮어쓰기는 없다. 카드·계통·비교 등의 기존 공통 표시 경로와 검토 이름 검색 경로가 동일 파일을 사용하므로 신규 19종에도 적용된다.

## 재현 방법과 실제 결과

`scripts/audit_korean_name_sources.py`는 전체 DB 추출 JSON과 세 원자료 추출을 읽어 모든 활성 종을 대조하고, 미표시 DB 후보를 종/이름별로 중복 제거한다. 검토 이름의 표시가 누락되면 비정상 종료한다.

```sh
PYTHONPATH=src /tmp/rg010-venv/bin/python scripts/audit_korean_name_sources.py \
  --inventory /tmp/rg-all-names-test.json \
  --source-dir /tmp/robingraph-korean-sources \
  --output docs/verification/assets/2026-10-09-korean-name-full-source-audit.json
```

결과: 11,131종 전수, 검토 국명 665, 표시 국명 665, 검토 이름 표시 결함 0, 영어 대체 10,466. 추가 출처 적용 후 아직 검토 목록 밖에 남은 DB 국명 후보는 408종이며 독립 근거 추가 검토 390, 이미 다른 종에 부여된 검토 국명과 충돌 12, 비한글 이름 6으로 구분했다. 이 408종을 모두 오류 또는 모두 올바른 국명으로 확정하지 않는다. 19종 중 5종은 기존 숨겨진 DB 이름을 가진 종이고 나머지 14종은 기존 추출에 국명도 없었다.

검증은 실제 TEST DB의 전체 이름 추출을 오프라인 공통 표시 함수로 대조한 것이다. 11,131번 HTTP 채팅 호출이나 Production 검증을 수행한 것으로 해석하지 않는다. 한국어 표시 단위 검사 6개 통과, taxonomy_lineage_neo4j 검사 31개 통과, 실패·건너뜀 0. 신규 기관 19종의 출처·정확학명·페이지, 기존 우선 이름 보존을 검증했다. 모의 저장소 검색 테스트와 실제 DB 추출 기반 감사를 구분한다.

## 변경 파일과 증거

- `src/robingraph/retrieval/species_ko_names.json`: 기관 근거 19종과 원자료 메타데이터 추가.
- `scripts/audit_korean_name_sources.py`: 전체 종/원자료 대조 재현 도구.
- `tests/test_korean_display_names.py`, `tests/test_taxonomy_lineage_neo4j.py`: 665종 계약과 신규 출처 검증.
- [기관 원문 27행 결정](../verification/assets/2026-10-09-korean-institutional-name-source.json): 추가·기존 유지·정확 연결 불가를 모두 보존.
- [전체 종 국명 감사](../verification/assets/2026-10-09-korean-name-full-source-audit.json): 원자료 해시, 408종의 검토 후보 및 사유, 기존 소스 전체 행 결과.

## 배포·커밋·한계

이 하위 작업은 커밋·배포를 수행하지 않았다. 최종 TEST→Production 배포와 전체 공통 데이터 검증 결과는 총괄 작업 기록에서 별도로 확정한다. 생태 형질·IUCN 자료나 DB 연결을 국명 근거로 채우지 않았다. 남은 408종에는 독립 기관 원문 확인이 필요하며, 추가 출처가 없는 종을 임의 번역해 수치를 줄이지 않는다.
