## 검증 결과

| 검증 | 결과 |
|---|---|
| 전체 자동 테스트 | **108개 통과**, 기본 실행에서는 opt-in Neo4j 테스트 20개 skip |
| 기존 gold 질문 | **15/15 통과** |

| 한국어 결합 검색 | 질문 2개 모두 관련 주제 문헌이 최상위, fallback 경고 0개 |

| 그래프 검증 | 종 10개, 관찰 100건, 문서 2개, 청크 4개; 비공개 좌표 속성·제한 관찰 0개 |
| 변경 형식 검사 | `git diff --check` 통과 |
| 한국어 검색 baseline | recall@3: fulltext `0.75`, vector/hybrid `1.00`; 모든 모드 정책 안전 |

실제 질문과 결과:

- `호수와 하천에서 관찰된 물새` → `fixture-chunk-waterbirds-1`, 검색어 임베딩 포함 2.250초.
- `공원과 숲의 새` → `fixture-chunk-woodland-2`, 검색어 임베딩 포함 1.031초.

실제 Jina 호출과 Neo4j 연결은 별도 수동 스모크 검증이다. 자동 테스트는 모의 HTTP 응답·합성 벡터를 사용하며 운영 API 키를 요구하지 않는다. 네 개 청크와 다섯 검색 질문의 결과는 연결 검증 및 baseline이며 일반적인 한국어 검색 품질이나 부하 성능을 입증하지 않는다. 기존 15개 gold도 그래프 답변 회귀 기준이다. 상세 측정과 실행 명령은 [임베딩 검증 기록](../embedding-adapter.md)에 있다.

## 종료 상태와 다른 PC에서 이어가기

- 테스트 DB는 로컬 `127.0.0.1:17687`의 Neo4j Community 2026.07.1을 사용했다. 실제 API 벡터를 제거하고 테스트 인덱스를 3차원으로 복구한 뒤 전체 테스트를 실행하고 서버를 종료했다.
- API 키와 DB 자격 증명은 Git ignore 대상인 로컬 `.env` 또는 secret store에만 둔다. CLI는 실행 디렉터리의 `.env`를 읽지만, 명시적 shell 환경 변수는 덮어쓰지 않는다.
- Git에는 코드·설정 예시·문서·fixture·잠금 파일이 포함된다. 로컬 DB와 임시 설치 파일, 실행 중인 서비스는 Git으로 이전되지 않는다.
- 원격 GitHub Actions 결과는 이 문서 작성 시점에는 미확인이다. push 후 해당 커밋의 실행 결과를 확인한다.

다른 PC의 `dev` 작업공간에서 로컬 변경을 확인한 뒤 실행한다.

```sh
git pull --ff-only origin dev
uv sync --locked --extra test
uv run --locked robingraph validate-fixture
uv run --locked robingraph evaluate-fixture
uv run --locked --extra test python -m unittest discover -s tests -q
```

DB 연결 설정이 없으면 DB 통합 테스트 20개는 skip된다. 실제 Jina 연결에는 `.env.example`의 설정을 로컬 `.env` 또는 환경 변수로 제공한다. 실제 임베딩용 인덱스는 512차원, 합성 벡터 통합 테스트용 인덱스는 3차원이므로 별도 테스트 DB를 사용한다. 상세 설정은 [개발 가이드](../development.md)와 [검색 가이드](../hybrid-retrieval.md)를 따른다.
