# RG-003 그래프 관계 탐색 후속 작업

RG-003은 RG-004~009의 상위 작업이다. 이번 작업에서 RG-005~009 구현과 NAS TEST 검증을 마쳤다. RG-004의 통칭·가축형 관계 확대 작업은 이전 완료 기록을 유지한다.

## 작업 결과

- RG-005: 관련 새 비교가 원래 설명을 보존하고 별도 답변 말풍선으로 추가된다. 반복 비교·오류 재시도·대화 초기화 이후 늦은 응답을 처리한다.
- RG-006: 해오라기의 야간 먹이 활동과 번식기 낮 활동을 출처에 근거해 설명한다. 원자료 `Nocturnal=0`은 검토 출처에서 확인할 수 있고 DB 값을 변경하지 않는다. 다른 종의 0도 야간 활동 부재로 단정하지 않는다. 모든 종의 생태 사실을 전수 검토한 작업은 아니다.
- RG-007: 활성 자료의 38개 범주값을 한국어로 표시한다. 알려지지 않은 값은 번역 확인 필요, 결측은 자료 없음으로 안내하며 원본 값은 보존한다.
- RG-008: 확인된 먹이 구성에 따라 여러 아이콘을 표시한다. 척추동물·물고기를 구분하고 서로 다른 자료의 비율을 합산하지 않는다. 카드 뒷면에서 기준과 출처를 확인한다.
- RG-009: 사용할 수 있는 사진이 없거나 제공처·파일 조회가 실패해도 설명과 카드를 유지한다. 상태 안내·재시도를 제공하며 다른 종의 사진으로 대체하지 않는다.

## 협업

Claude가 비교 말풍선·먹이 아이콘·사진 UI와 자동 테스트를 구현했다. Antigravity가 야행성 원자료와 문헌을 조사했으며, Codex가 출처 검증·백엔드·번역·통합 검토·NAS 배포와 실제 브라우저 검증을 수행했다. 단순한 에이전트 표시 이름을 실제 실행 모델의 확인으로 간주하지 않았다.
