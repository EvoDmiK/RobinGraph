# RG-301 첫 설명 전체 표시와 선택적 관계 탐색

작성일: 2026-10-08. 대상: NAS TEST. ‘더 알아보기’ 뒤로 미룰 대상을 관계 탐색으로 좁힌 사용자 후속 요청을 반영했다. 앞선 자동 후속 로딩 및 사진·설명 클릭 조회 기록은 당시 구현 이력이며 현재 동작은 이 문서를 따른다.

## 요청 배경·목표

사용자는 흰뺨검둥오리 예시에서 기본 정보·학명·체중·서식 환경·먹이·보전 상태, 부리/날개/꼬리 측정값, 생활과 먹이, 외부 자료의 외관 설명·재미있는 사실을 처음부터 보고 싶다고 명시했다. 아종·통칭/가축형·같은 서식 환경/먹이 생태의 새는 나중에 탐색하도록 요청했다. 이전 구현은 사진·외부 설명·추천 모두를 ‘더 알아보기’ 클릭 후 조회하여 설명 자체가 첫 답변에서 빠졌다.

## 원인·변경 전후

채팅이 `defer_enrichment:true`를 보내 기본 프로필만 먼저 받던 것이 첫 설명 누락의 원인이었다. 현재는 전체 프로필을 처음 요청하고 `defer_discovery:true`로 일반 소개의 자동 추천만 생략한다. ‘더 알아보기’는 처음 접힌 관계 탐색 메뉴이며 펼치기만으로 조회하지 않는다. 내부에서 원하는 항목을 선택할 때 해당 API를 조회한다. 아종·관련종·생태 관계를 직접 묻는 경우 요청한 답변은 즉시 보여준다.

외부 외관 설명이 있으면 `species_sections`가 측정값을 대체하던 별도 원인도 확인했다. 측정값 3개와 외부 설명 2개를 같은 외관 섹션에 합치고, 화면의 기존 4개 제한을 외관만 5개로 바꿨다. 같은 외관 제목을 중복 생성하지 않으며 각 자료의 출처를 보존한다.

## 변경 파일·구현

- `src/robingraph/api/app.py`: `ChatRequest.defer_discovery`를 기본값 `false`로 추가했다. 일반 소개의 선택적 `similar_species` 자동 조회만 억제한다. 직접 관련종·아종·생태 질문의 조회는 그대로 처리한다. 이름 해소에 필요한 검토된 통칭 관계 조회는 정확성 검증이므로 유지한다.
- `src/robingraph/retrieval/species_profile.py`: 출처 있는 측정값과 외부 외관 설명을 함께 반환한다. 기존 네 개 섹션 구조를 유지해 재미있는 사실이 잘리지 않는다.
- `src/robingraph/api/static/chat.js`: 채팅에서 `defer_discovery:true`를 전송하고 전체 설명을 첫 답변에 표시한다. 일반 소개의 근연 TOP3·생태 관계·아종·통칭/가축형 탐색기를 모두 ‘더 알아보기’ 안에 넣었다. 초기 추천이 없어도 TOP3 버튼이 `/v1/taxa/similar`를 클릭 시 호출한다. 외관 섹션은 최대 5개를 표시한다.
- `tests/test_species_profile.py`: 전체 외관·재미있는 사실·측정값 초기 포함, 선택적 관계 조회 억제, 직접 아종 질문의 즉시 응답을 검증했다.
- `tests/frontend/chat_ui.test.js`: 초기 다섯 외관 항목·생활/먹이·재미있는 사실 표시, 메뉴 접힘, 메뉴 열기 전후 추가 조회 0건, 내부 TOP3 클릭 시 추천 API 1회·프로필 재조회 0건을 검증했다.
- `docs/jev-intent-routing.md`: 현재 초기 설명·선택적 관계 탐색 계약으로 갱신했다. 이전 `defer_enrichment` API와 UI 지원은 호환성을 위해 남기며 현재 채팅에서는 보내지 않는다.

## 협업·독립 검토

`progressive_chat_ui`가 JS와 프런트엔드 테스트를 구현했다. 주 담당은 API·프로필 변환·Python 테스트·통합 검증·NAS 배포·문서화를 담당했다. `progressive_review`는 읽기 전용 검토와 독립 프런트엔드/프로필 테스트를 수행했으며, 측정값 대체와 화면 항목 제한을 추가 지적했다. 두 문제를 수정한 최종 diff에서 배포 차단 문제 없음을 확인했다. 실행 모델 이름은 별도 증거가 없어 추정해 기록하지 않는다.

## 한계·후속 사항

전체 설명·사진을 처음 조회하므로 외부 제공자 시간이 첫 답변 지연에 다시 포함된다. 이전 기본 프로필만 먼저 표시하던 속도 수치는 현재 구현에 적용하지 않는다. 출처가 없거나 제공자가 실패한 자료는 기존 경고/자료 없음 정책을 유지하며 생성 내용을 새 사실로 단정하지 않는다. ‘더 알아보기’는 자료 전체를 한꺼번에 조회하는 버튼이 아니라 원하는 관계 항목을 선택하는 메뉴다. 별도 백로그와 최후순위 보류 작업은 진행하지 않았다.
