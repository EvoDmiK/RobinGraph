# RG-003 — 자연어 질문에 맞춘 그래프 답변

사용자의 요청은 ‘왜가리는 무엇을 먹고 사니?’, ‘청둥오리와 비슷한 종은 어떤게 있니?’ 같은 질문에 맞춰 그래프를 조회하고 응답하는 기능이다. 이전에 생태 탐색 버튼 추가로 범위를 좁혀 완료 처리했던 해석을 정정했다. 기존 버튼과 관계 조회는 보조 경로로 유지하고 질문별 직접 답변을 추가했다.

## 구현

- 먹이·서식 환경·활동 시간·외관·관련 종·생태 관련 종의 질문과 지원하는 변형에서 정확한 종 이름과 주제를 추출한다. 인식된 질문은 임베딩 분류 없이 처리한다.
- 먹이 질문은 출처가 있는 먹이 구성비 또는 자료의 범주를, 관련 종 질문은 같은 속·과의 실제 후보와 분류 출처를 바로 제공한다.
- ‘같은 속’ 또는 ‘같은 과’를 명시하면 해당 그룹만 표시하고, 먹이·서식 환경이 비슷한 새를 물으면 해당 생태 범주만 조회한다.
- 서식지 질문에는 확인된 환경 범주를 제공하며 실제 지역·분포를 추측하지 않는다. 해오라기 활동 시간은 검토 출처의 야간 활동과 번식기 낮 활동을 유지한다.
- 질문에 해당하는 답변을 설명창 첫 부분에 표시하고 후보 목록을 바로 펼친다. 사용자가 추가 탐색 버튼을 누를 필요가 없다. 후보의 비교는 기존처럼 새 말풍선에 두 종의 자료·카드를 제공한다.
- `result.kind=profile`과 기존 프로필을 유지하고 선택 필드 `question_answer`에 주제·답변·출처별 항목·직접 조회한 관계를 넣는다.
- 관련 종 조회에서도 한국어 이름이 없으면 허용된 영어 이름을 사용한다. 허용 정책·분류판·종 ID를 양쪽에서 검증한다.

## 잘못된 대상·근거 없는 답변 방지

- 질문의 이름과 종 필터가 다르면 확인 질문을 반환한다. 다른 종의 프로필을 원래 질문의 답으로 표시하지 않는다.
- 고유 통칭은 검토된 연결 종의 taxon ID·개념집합·분류판이 프로필과 일치할 때만 직접 답한다. 이름 관계 출처도 보존한다.
- 여러 종을 뜻하는 ‘까마귀’와 가축형 ‘집오리’는 후보·관계 구분을 유지하며 야생 종의 먹이를 임의로 대신 답하지 않는다.
- 먹이 구성비는 양의 유한한 값만 표시하고 다른 자료를 합산하지 않는다. 수생동물 포식이라는 범주만으로 특정 먹이를 추정하지 않는다.
- 질문에 맞는 출처가 없으면 미확인으로 답한다. 아종의 부모 종 참고 형질을 아종의 먹이로 사용하지 않는다.
- 명시적 문헌·관찰 경로는 유지한다. 자유로운 모든 한국어 표현이나 이전 대화의 대명사·생략 질문까지 처리한 범위는 아니다.

## 검증

- Python 전체 524건: 492건 성공, 외부 연동 32건 제외, 실패 없음. 질문 처리 8건과 영어 이름 후보 회귀 검증 포함.
- 프런트엔드 121건 전부 통과. 질문별 답변·자료 출처·바로 열린 후보·추가 조회 없음·별도 비교·분류판 변경·통칭 출처 확인.
- 실제 NAS `POST /v1/chat` 10개 질문을 검증했다. 왜가리의 물고기 60% 등 출처 있는 구성비, 청둥오리의 고방오리 등 같은 속·과 후보, 해오라기 검토 활동 시간, 왜가리 습지, 먹이 생태 범주만의 후보를 확인했다.
- ‘학’은 연결된 두루미의 자료와 이름 출처를 보존했다. ‘까마귀’·‘집오리’는 clarify, 직접 먹이 자료가 없는 청둥오리 아종 conboschas는 abstain을 확인했다.
- `Trochilus polytmus` 질문에서 같은 속의 `Black-billed Streamertail` 등 영어 이름 후보를 확인했다.
- Chromium 320·390·1280px에서 요청한 두 질문, 추가 버튼 클릭 없이 펼쳐진 후보, 새 비교 말풍선·카드 두 개, 이어지는 활동 시간 질문을 확인했다. 가로 넘침·페이지 오류 없음. 먹이가 비슷한 새 질문에서 먹이 생태 그룹만 바로 표시하는 것도 확인했다.
- GPT-6.1-sol은 UI·테스트, GPT-6-sol은 이름·분류판·출처 정책의 독립 검토, Codex는 질문 처리·API·근거 구성·통합 수정·배포·실환경 검증을 담당했다. graphify AST 갱신 완료.
