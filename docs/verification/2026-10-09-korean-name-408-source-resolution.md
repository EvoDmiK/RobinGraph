# 잔여 한국어 이름 408종 원문 조사와 185종 반영

## 요청과 범위

사용자는 일부 종만 고치는 방식 대신, 한국어 이름이 있는데도 영어로 표시되던 후보 408종 전부를 처리하도록 요청했다. 이 문서는 국명 영역만 다룬다. 형질 공백 503종과 보전평가 미연결 447종의 조사·배포는 병행 작업이며 이 문서의 검증 결과에 포함하지 않는다.

입력은 `assets/2026-10-09-korean-name-full-source-audit.json`의 `unreviewed_graph_species` 408종이다. 원래 처분은 독립 출처 확인 필요 390종, 기존 검증 종과 이름 충돌 12종, 한국어가 아닌 후보 6종이었다. 기존 표시용 참고 국명은 665종이었다.

## 결과와 미해결 범위

408종 모두 개별 원문 조회와 처분을 기록했고, **185종의 새 참고 국명을 실제 표시 데이터에 추가하여 총 850종**이 되었다. 기존 665종의 이름·학명·출처 레코드는 변경하지 않았다. 408종 모두 이름을 확보했다는 뜻은 아니다.

| 최종 처분 | 종 수 | 의미 |
|---|---:|---|
| 독립 원문으로 확인하여 반영 | 185 | 현재 종의 학명·국명 쌍을 확보하고 기존 검증명과 충돌하지 않음 |
| 추가 독립 근거 필요 | 130 | 조회한 원문과 검색 결과에서 채택 가능한 쌍을 확보하지 못함 |
| 접근 오류 또는 독립 근거 미확보 | 75 | Avibase 기본·영어·한국어 URL을 모두 시도했으나 접근 실패; 이름 부재로 판정하지 않음 |
| 현재 다른 종과 국명 충돌 | 16 | 과거 분류의 국명을 다른 현재 종에 전용하지 않음 |
| 한국어가 아닌 후보이며 대체 근거 미확보 | 2 | 영어·학명을 한국어 이름으로 승격하지 않음 |

비한국어 후보 6종 중 4종은 별도의 기관 원문에서 한국어 이름을 확보했다. 이름을 새로 번역하거나 Wikidata 후보 자체를 출처로 간주하지 않았다. 원래 충돌 12종 외에도 신규 출처 대조 과정에서 충돌을 추가 발견했다. 위 표는 원래 분류가 아니라 최종 처분 기준이다.

## 원인과 채택 기준

이전 후보 목록에는 공개 그래프에서 가져온 미검증 이름과 오래된 분류 체계의 국명이 섞여 있었다. 실제로 산림청 원문에 `Pica pica=까치`, `Coturnix coturnix=메추라기`, `Aquila rapax=초원수리` 같은 쌍이 있더라도, 기존 검증된 현재 종의 이름을 덮어쓰면 분류 변경에 따른 오연결이 재발한다. 해당 이름들은 현재 기준의 다른 종과 충돌하므로 추가하지 않았다.

반대로 `Carduelis carduelis`는 산림청에 홍방울새로 기록되어 있지만 현재 법령 원문의 국명·학명 표에서 오색방울새를 확인했다. 기존 `Acanthis flammea=홍방울새`를 유지하고 새로운 종에는 오색방울새를 채택했다. 법령은 이 작업에서 이름 쌍의 근거로만 사용했으며 CITES 부속서나 법적 보호 지위를 IUCN 등급으로 바꾸지 않았다.

모든 신규 레코드는 `source-reference`다. 국가 차원의 공식 국명 지정이라고 주장하지 않는다. 학술 논문에서 가칭으로 제안된 흰목딱새와 Avibase 통합목록의 참고 국명도 각각 그 성격을 출처 제목과 locator에 남겼다. 출처의 학명, 현재 AviList 종 ID, 학명, 영어 이름의 정확 대응을 유지하며 아종 이름을 임의로 종으로 확대하지 않는다.

## 조사한 원문과 실제 범위

1. **산림청 백두대간 동물종 정보:** 대상 408종 전부 학명 검색. 각 응답의 URL·SHA-256·정확 일치 행을 기록했다. 정확한 국명·학명 쌍 187개를 확보했으나 기존 검증명 충돌 17개를 그대로 반영하지 않았다. 후속 고시 대조에서 오색방울새를 교정했다. 최종 신규 163종의 주 출처가 산림청이다. 미검출 221종에 대해서는 종소명 검색도 별도로 수행해 옛 속명·철자 사례를 확인했지만, 검증되지 않은 동의어를 자동 연결하지 않았다.
2. **국가법령정보센터 국제적 멸종위기종 목록:** PDF 전체 67쪽 텍스트에서 대상 학명을 대조하고 채택한 쌍의 실제 쪽수를 보존했다. 최종 14종의 주 출처다. 여러 단 표의 인접 이름이나 부속서 설명이 이름으로 잘못 추출된 행은 제외했다. 자동 텍스트 미검출은 PDF에 이름이 절대 없다는 의미가 아니다.
3. **Cornell Lab of Ornithology eBird taxonomy v2025:** 공식 배포 XLSX의 `full_sparse` 전체를 검사했다. 한국어 값이 있는 925행을 추출하고 category가 species인 정확 학명과 비교했다. 북극제비갈매기와 작은발땅꾼수리 2종을 채택했다. 집오리처럼 범위가 넓은 이름을 독립적인 Muscovy Duck 이름으로 우선하지 않았다.
4. **Avibase / Birds Canada:** eBird concept ID로 408종 전부의 종 페이지를 조회했다. 최초 접근 오류 126건은 공식 페이지의 영어 옵션으로 재시도했고, 최종 미해결 중 75건은 한국어 옵션까지 추가 시도했다. 성공 페이지에서 한국어 필드가 없는 경우와 접근 오류를 구분했다. 분류표의 AviList 2025 개념과 한국어 필드가 함께 확인되는 프르제발스키되새 1종을 추가했다. Avibase에도 과거 범위의 한국어 이름이 있어 출처가 있다는 이유만으로 전부 채택하지 않았다.
5. **별도 원문 검토:** 후지필름 코리아 사진작가 원고의 정확 학명 캡션에서 푸른박새·뿔박새 2종, 한국조류학회지 원문 메타데이터·초록에서 흰목딱새 1종, 서울대공원 동물 보유현황에서 사랑앵무 1종, 극지연구소 원문 PDF의 국명·학명 표에서 턱끈펭귄 1종을 확인했다. 극지연구소 본문 일부의 학명 철자 오기는 사용하지 않고 차례와 목록 표의 정확한 학명을 사용했다.
6. **잔여 227종 개별 검색:** 181종을 먼저 확보한 뒤, 나머지 227종 각각에 대해 학명과 후보 국명을 함께 검색했다. 원본 위키·자동 번역·이미지 판매 사이트만 발견되는 경우에는 국명을 승격하지 않았다. 검색어, 4종 단위 검색 묶음의 구성, 결과 URL 목록과 결과 묶음 SHA-256을 개별 감사 레코드에 남겼다. 묶음의 모든 URL이 해당 종의 근거라는 뜻은 아니며, 실제 채택 근거는 `selected`에 별도로 명시한다.

## 변경 파일과 동작

- `src/robingraph/retrieval/species_ko_names.json`: 185개 정확 종 ID에 참고 국명·출처·locator·원문 학명을 추가했다. `review_batch=2026-10-09-ko408`로 기존 자료와 식별할 수 있다. PDF는 실제 쪽수, 다운로드 원문은 SHA-256도 기록했다.
- `tests/test_korean_display_names.py`: 전체 개수 850을 검증하고, 185개 모두의 정확 식별자·학명 대응, 출처 locator 존재, 기존 이름 충돌 방지, 잘못된 학명 입력 거부를 검사한다. 전체 408개 처분과 실제 반영 목록이 일치하는지도 검증한다.
- `assets/2026-10-09-korean-name-408-resolution.json`: 408종 전체의 입력 후보, 각 조사 경로, 채택·보류 이유, 채택한 정확 근거를 담는다. 영어 유지 항목도 어떤 독립 원문을 조사했는지 확인할 수 있다.

이전에는 185개 신규 대상이 미검증 그래프 이름 대신 영어로 표시되었다. 이제 기존 공통 표시 함수가 출처가 있는 참고 국명을 사용한다. 특정 화면이나 특정 종만 예외 처리하지 않았다. 영어 이름·학명·분류 ID는 유지한다. 미확인 223종은 영어 표시를 유지하며, 조회되지 않았다는 이유로 가짜 국명을 생성하지 않는다.

## 남은 한계와 후속 기준

223종의 미해결은 숨기지 않는다. 접근 오류는 자료 부재와 다르며, 독립 원문을 찾지 못했다는 결과도 한국어 이름이 존재하지 않는다는 증거가 아니다. 향후 기관 목록·전문 도감·학술 기록에서 정확한 쌍이 확인되면 동일 레코드에 근거를 추가해 반영할 수 있다. 옛 분류 범위와 겹치는 이름은 현재 종 개념의 분할·통합 근거를 먼저 확인해야 한다.

원문 출처를 연결한 참고 국명이라는 범위를 유지하며, 408개 전수 조사 완료와 408개 전부의 이름 해결을 혼동하지 않는다.
