# RG-013 추가 자료를 ‘더 알아보기’ 클릭 후 조회

작성일: 2026-10-08. 대상: NAS TEST. 사용자 요청에 따른 후속 변경이며 기존 자동 후속 로딩 기록을 대체하는 현재 동작이다.

## 배경·목표와 확인 근거

첫 답변을 먼저 보여주고 사진·외부 설명·일반 소개 추천을 자동 조회하던 구현에 대해 사용자가 추가 정보는 ‘더 알아보기’ 버튼을 눌렀을 때 나오도록 요청했다. 기존 `buildDeferredEnrichment`가 구성 직후 조회를 시작하는 것이 자동 호출의 원인이었다. 기본 답변·아종 목록은 먼저 보여주고, 필요할 때만 추가 API를 호출하도록 변경했다. Jev 의도 분류나 DB 조회 계약 변경은 이번 작업에 해당하지 않는다.

## 변경 전후·구현 파일

- `src/robingraph/api/static/chat.js`: 즉시 실행하던 추가 조회를 버튼 클릭으로 옮겼다. 클릭 전에 프로필·추천 API를 호출하지 않으며 클릭 즉시 시작 상태와 비활성 상태를 설정해 중복 클릭을 막는다. 일반 소개는 프로필·추천을 병렬 조회하고 아종 등 집중 질문은 프로필만 조회한다. 사진 대기 안내도 실제 버튼 동작에 맞췄다.
- 새 질문·비교는 이미 시작한 추가 조회만 취소한다. 미사용 이전 답변의 버튼은 원래 종의 문맥으로 작동한다. 대화 지우기는 미사용 버튼과 늦은 응답도 무효화한다. 최초 종 ID·개념집합·분류판의 일치 검증, 출처·경고, 기존 답변 유지와 비교용 프로필 갱신은 유지했다.
- `src/robingraph/api/static/styles.css`: 버튼 너비·최소 높이·색·비활성 표시를 기존 화면 스타일에 맞췄다.
- `tests/frontend/chat_ui.test.js`: 클릭 전 0회·클릭 후 1회 요청, 중복 클릭 방지, 새 질문 후 이전 버튼, 대화 삭제 후 무효화 회귀 검증을 추가했다.
- `docs/jev-intent-routing.md`: 자동 호출 설명을 현재 버튼 호출 및 취소 규칙으로 갱신했다.

## 협업·검토

`progressive_chat_ui` 에이전트가 JS·프런트엔드 테스트를 구현했다. 주 담당은 CSS·통합 검증·NAS 배포·문서화를 수행했다. `progressive_review` 에이전트는 읽기 전용 독립 검토와 프런트엔드 테스트를 수행했으며 배포를 막는 문제를 발견하지 않았다. 실행 모델 이름은 이번 검증 증거에서 별도로 확인하지 않아 추정해서 기록하지 않는다.

## 한계·후속 사항

사진·추가 설명 조회 자체의 외부 응답 시간은 남는다. 버튼을 누르지 않으면 그 조회가 발생하지 않는다. 이미 시작한 요청은 새 질문 시 취소되며 동일 버튼을 재시도하는 UI는 이번 범위에 추가하지 않았다. 실패는 기존 부분 경고로 표시하고 새 질문으로 다시 조회할 수 있다. 외관을 직접 묻는 질문은 외관 설명이 필수 답변이므로 기존 전체 조회를 유지한다. 직접 API의 `defer_enrichment=false` 기본값도 유지한다. 다른 신규 백로그와 최후순위 보류 작업은 착수하지 않았다.
