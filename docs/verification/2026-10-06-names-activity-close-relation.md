# 국명 보완·일반 활동 시간·근연 관계 동점 정렬

국내 목록 밖의 한국어 이름도 학명과 출처로 검증하도록 범위를 보완했다. 전체 활성 AviList 11,131종과 IOC v15.2 한국어 목록을 대조하고, 서울대공원 조류 종별 자료 45건을 확인했다. IOC 25종과 서울대공원 25종을 추가해 확인된 한국어 이름 646종, 영어 표시 10,485종이다. 이미 다른 활성 종에 할당된 이름, 학명 오류·축약·사육형, 의심되는 국명은 자동으로 보완하지 않는다. 자료 URL과 원본 이름, 제외 이유를 JSON에 보존했다. Nankeen Night Heron은 검증된 한국어 이름을 찾지 못해 영어를 유지한다.

## 활동 시간

표시는 `야행성` / `야행성 아님`으로 통일한다. 번식기·이동기 등 특별한 때의 일부 활동으로 분류를 뒤집지 않고 평소 주된 먹이 활동을 기준으로 한다. ‘야행성 아님’은 밤에 절대 활동하지 않는다는 뜻이 아니다. 결측은 false로 간주하지 않고 자료 없음 상태를 유지한다.

기본 EltonTraits 값은 [자료 정의](https://www.esapubs.org/archive/ecol/E095/178/metadata.php)의 ‘주요 먹이 활동이 밤인가’ 분류를 사용한다. 원자료와 별도 종별 문헌이 충돌하는 해오라기(Nycticorax nycticorax)는 [Cornell Life History](https://www.allaboutbirds.org/guide/Black-crowned_Night_Heron/lifehistory)의 평소 저녁~새벽 취식을 근거로 야행성으로 보정한다. 낮 활동의 번식기 예외는 분류에 반영하지 않는다. Nankeen Night Heron(Nycticorax caledonicus)은 [BirdLife Australia Feeding](https://birdlife.org.au/bird-profiles/nankeen-night-heron/)의 밤 취식을 근거로 야행성으로 보정한다. 검토에서 대체한 원래 값과 출처는 접힌 원자료 기록에 보존한다. 원본 DB의 코드를 바꾸지 않는다.

## 흰뺨검둥오리의 비교 후보

기존 점수는 같은 속 50·같은 과 30·서식 환경 10·먹이 10이며, 모두 100점이면 학명순이었다. 그래서 청둥오리보다 고방오리·Andean Teal이 먼저 표시됐다.

[Wang et al. (2019), Current Zoology](https://academic.oup.com/cz/article/65/5/589/5144203)에서 확인한 흰뺨검둥오리와 청둥오리의 근연 관계를 **동점 정렬의 우선 근거**로 추가했다. 점수는 유지하며, 같은 활성 릴리스·속/과 조건을 만족한 두 종에만 상호 적용한다. 근거는 ‘문헌으로 확인한 근연 관계 · 동점 우선’으로 출처와 함께 보인다. 전체 종의 계통 거리를 계산한 결과라고 주장하지 않는다. 자료가 없는 조합은 기존 학명·ID 순서를 유지한다. 높은 기존 점수를 가진 후보보다 낮은 후보를 올리는 기능은 아니다.

## 로컬 검증

- Python 535개 실행, 성공(환경 의존 40개 생략).
- 프런트엔드 125개 성공.
- 전체 활성 종 11,131개의 국명/영어 표시 개수와 원본 학명·영명 보존을 확인했다.
- 활동 시간의 두 표기, 해오라기 두 종의 검토 우선 적용, 결측 유지와 원자료 보존을 확인했다.
- 근연 관계 동점 우선, 다른 릴리스 차단, 낮은 점수 후보를 올리지 않는 조건을 확인했다.
- graphify AST 갱신 완료.
