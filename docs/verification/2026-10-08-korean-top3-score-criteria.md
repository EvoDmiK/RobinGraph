# 검증 국명 우선 TOP 3 선정과 점수 기준 화면

작성일: 2026-10-08. 대상: NAS TEST. 사용자가 청둥오리 비교 카드의 영어 1위와 긴 점수 설명을 지적하고, ‘국명이 있는 후보를 먼저 선정하고, 그 안에서 점수순으로 표시’하는 정책을 명시했다.

## 배경·확인한 원인

직전 `cb1cafb` 수정은 같은 속·과의 목록 제한 이전에 검증 국명을 우선했지만, 가중 비교 TOP 3는 전체 점수 순서로 유지했다. 따라서 청둥오리의 1위 Indian Spot-billed Duck 100점, 2위 흰뺨검둥오리 98.28점, 3위 Philippine Duck 96.55점 중 검증 국명이 없는 1·3위가 영어로 표시되는 것은 직전 정책대로의 결과였다. 사용자의 추가 확인으로 이제 TOP 3의 후보 선정에도 국명 우선을 적용한다. 이는 알려진 이름의 가독성을 위한 추천 정책이며 한국어 이름으로 과학적 근연 순위를 추정하지 않는다.

기존 `buildRelatedExplorer`는 서버의 긴 `note`를 한 문단으로 표시했다. 가중치·자료 부족 시 계산·점수 해석을 한 번에 읽어야 했으므로 네 가지 비중과 상세 설명을 나누었다.

## 변경 전후·구현

- `src/robingraph/retrieval/similar_species.py`: 전체 활성 종의 기존 계통·분류·생태 점수를 먼저 계산한다. 점수가 있는 후보와 검증 국명표 ID의 교집합, 기존 점수 상위 3종만 이름을 조회한다. 후보의 종 ID·학명·원자료 영어 이름을 대조해 검증된 국명 후보를 점수 내림차순·학명·ID로 최대 3개 고르고, 부족한 수만큼 기존 점수 상위 영어 후보로 채운다. 점수·근거·계통 부족 시 재환산은 변경하지 않았다. 예상 밖 ID나 중복 이름 투영은 계속 거부한다.
- 응답의 `ranking.priority`는 `korean_name_then_weighted_score`이며 후보 그룹과 설명도 국명 우선 정책을 밝힌다. `ranking.method` v3는 점수 계산이 동일하므로 유지한다. 전체 활성 종의 점수 상위 3종이라는 의미로 표현하지 않는다.
- `src/robingraph/retrieval/species_questions.py`: 새 정책의 텍스트 답변 순번을 ‘추천 1’ 형식으로 표시한다. 다른 정책은 기존 순위 형식을 유지한다.
- `src/robingraph/api/static/chat.js`: 점수 기준 패널에 ‘한국어 이름 우선 · 점수순’과 계통·분류·서식 환경·먹이 생태 4개 비중 배지를 표시한다. 비중은 실제 `ranking.weights`에서 읽고 분류는 같은 속+같은 과 비중의 합이다. 정확한 키·유한 숫자·범위·합계 100을 검증하며, 지원하지 않는 형식은 기존 설명을 안전하게 표시한다. 계산 방식·자료 한계·원래 서버 설명은 처음 접힌 상세에 보존한다. 카드 순번·접근 이름·비교 설명도 ‘추천 1·2·3’을 사용한다.
- `src/robingraph/api/static/styles.css`: 점수 패널·네 가지 비중의 간격과 색·테두리를 정리하고, 390px에서는 2×2로 보여준다.
- `tests/frontend/chat_ui.test.js`: 가중치·잘못된 데이터·정책 문구·접힌 상세·직접 TOP 3 한 벌·추천 순번을 검증한다. `tests/test_similar_species_korean_priority.py`에 서버 선정·이름 검증·오류·API 순번의 회귀 10개를 추가했다.
- `docs/korean-display-names.md`: 현재 TOP 3 정책을 갱신하고 직전 기록을 이력으로 구분한다.

국명 자료의 신규 수집·임의 번역, 원본 DB 이름·검색 별칭·Jev 프롬프트·환경 변수 변경은 하지 않는다.

주 담당이 사용자 정책 확인·서버 수정·통합 검증·NAS 배포·문서화를 담당했다. `progressive_chat_ui`가 점수 기준 패널·반응형 CSS·프런트엔드 회귀를 구현했다. `progressive_review`가 전체 활성 종 점수 계산을 유지하면서 제한된 이름 조회로 검증 국명 후보를 고르는 방법을 검토하고 서버의 선정·대체·오류 회귀를 작성했다. 새 10개 회귀의 독립 실행을 통과했고 백엔드 최종 검토에서 차단 문제는 없었다. 실제 실행 모델 이름은 근거 없이 추정하지 않는다.

## 한계·후속 사항

한국어 이름 후보의 점수가 영어 후보보다 낮을 수 있다. 표시 순번은 추천 순서이며 전체 점수 순위가 아니다. 검증표가 없는 분류판이나 국명 후보가 없는 질문은 영어 이름 후보로 대체된다. 실제 진화 거리·유전 유사도·확률로 점수를 해석하지 않는다. 외부 국명 원자료를 새로 검증한 작업이 아니다. 다른 백로그와 보류 작업은 진행하지 않는다.
