# ADR-0003: MVP 데이터 라이선스 허용 정책

- 상태: Proposed
- 작성일: 2026-09-03
- 근거 입력: `docs/data-source-decision-input.md`

## 맥락

관찰, 미디어, 문헌은 데이터셋·레코드·자산마다 라이선스가 다르다. 비상업 로컬 데모에서 가능해 보이는 사용도 상업 서비스 전환, 임베딩, 청크 저장, 파생 답변에서 다시 검토해야 할 수 있다. 1인 MVP에서 복잡한 예외 정책과 향후 데이터 제거 작업을 피해야 한다.

## 결정

MVP의 검색·임베딩·답변 생성 기본 허용 목록은 다음 세 유형으로 제한한다.

- CC0
- CC BY 3.0/4.0
- 공공누리 제1유형

라이선스가 자산별로 다른 소스는 각 레코드나 미디어가 위 허용 목록임을 확인한 경우에만 적재한다. CC BY-NC, CC BY-ND, CC BY-SA, 공공누리 제2~4유형, 사용자 정의 약관, 계정 기반 제한 데이터, 미확인 상태는 기본 검색 컨텍스트와 임베딩에서 제외한다.

## 이유

- 비상업·변경금지·동일조건 조항을 임베딩, 청크, 생성 답변에 적용하는 법적 해석을 MVP가 떠안지 않는다.
- 상업 전환 때 대규모 벡터 삭제와 답변 정책 변경을 피한다.
- license allowlist를 단순한 적재 gate로 구현할 수 있다.
- provenance와 attribution 검증 범위가 명확해진다.

## 동작별 정책

| 상태 | SourceRecord 최소 보존 | 그래프/전문 인덱스 | 임베딩 | 생성 근거 | 파일 재배포 |
|---|---:|---:|---:|---:|---:|
| CC0 | 허용 | 허용 | 허용 | 허용 | 허용 |
| CC BY 3.0/4.0 | 허용 | 허용 | 허용 | attribution 조건으로 허용 | attribution 조건으로 허용 |
| 공공누리 제1유형 | 허용 | 허용 | 허용 | 출처표시 조건으로 허용 | 출처표시 조건으로 허용 |
| 그 외 명시적 라이선스 | 감사용 최소 메타데이터만 | 금지 | 금지 | 금지 | 금지 |
| unknown/review_required | 감사용 최소 메타데이터만 | 금지 | 금지 | 금지 | 금지 |

“감사용 최소 메타데이터”도 원 약관이 수집 자체를 금지하면 보존하지 않는다. 원본 파일이나 본문을 먼저 내려받은 뒤 정책을 판단하는 흐름을 사용하지 않는다.

## Attribution

CC BY와 공공누리 1유형의 답변·미디어 카드는 제목/자산명, 제작자 또는 제공기관, 원문 URL, 라이선스명과 URL, 수정 여부, 접근일을 표시한다. 하나의 답변에 여러 출처가 있으면 출처별 attribution을 합치지 않는다.

## 검토한 대안

- **비상업 MVP에서 BY-NC 허용**: 사용할 수 있는 관찰과 미디어가 늘지만 상업 전환 시 전체 삭제·재색인이 필요하고 “비상업”의 범위를 관리해야 한다.
- **ND/SA 자료 조건부 허용**: 문헌과 이미지 선택지가 늘지만 청크·임베딩·생성 답변의 파생물 판단이 필요하다.
- **모든 데이터를 내부 색인 후 응답만 제한**: 수집과 내부 처리 자체의 허용 여부가 불명확하며 정책 위반 자료가 모델 컨텍스트에 섞일 위험이 있다.

## 재검토 조건

특정 소스가 MVP 가치에 필수인데 허용 목록 밖인 경우에만 그 소스의 정확한 약관과 사용 방식에 대해 별도 검토하고 예외 ADR을 만든다. 전체 정책을 느슨하게 바꾸지 않는다.

## 확정 전 조건

- 공공누리 1유형의 표시 양식을 실제 응답 카드 형식과 대조한다.
- 외부 데이터 조사 문서의 미확인 항목을 공식 원문 또는 제공기관 서면 답변으로 확인한다.
- 서비스의 상업/비상업 목표를 명시한다.
