# 한국어 통칭·별칭 및 사육조 조사

2026-10-03 Claude 조사 후 Codex가 출처·분류판을 대조하고 런타임 목록에 통합했다. 이 후보 파일은 조사 분담 기록이며 최종 조회 목록은 [확대 목록](../name-relations-coverage.md)과 패키지 manifest를 기준으로 한다.

국립국어원 사전의 통칭·별칭 의미, 국립생물자원관 센서스 및 서울대공원의 한국어 이름·학명 대응을 대조했다. 예전 분류명의 변경은 프로젝트에 고정된 AviList 2025b 원본으로 확인했다. 반려 사육만으로 가축화라고 판정하지 않았다. 십자매 연구는 Suzuki et al. (2021), doi:10.1101/2021.03.23.436696의 **bioRxiv 사전 공개 논문**이며, 금사조·카나리아 자료는 Bovo et al. (2023), Animal Genetics, doi:10.1111/age.13331이다.

## Deferred or excluded (with reasons)

- **Valid species names; not shadowed** (each has a single-species dictionary entry or census row):
  - 올빼미 (「올빼미」 single species; ≒계효 …)
  - 소쩍새 (single species)
  - 독수리 (「독-수리」 single species; census *Aegypius monachus* 독수리)
  - 갈매기: the dictionary defines it as a group, but the NIBR census uses 갈매기 as the species name of *Larus canus*. Using it as a group term would shadow that species.
  - Wider "eagle = 독수리" usage has no source evidence, so it was not added.
- **Same-name pets (no alias to add, and a term would shadow):**
  - 문조: 「문조1」 says pets are kept; the 서울대공원 idx=1433 page has empty 학명.
  - 카나리아: the species name and the domestic usage coincide. Only the old aliases 금사조·금사작 were used.
  - 사랑앵무 and 왕관앵무 are themselves established names.
- **문조 target note:** in pinned AviList, Java Sparrow is *Padda oryzivora*; *Lonchura oryzivora* has no species row. Not used, since 문조 is deferred.
- **금화조:** not added. The *Taeniopygia guttata*/*castanotis* split was not researched (in pinned AviList, *T. castanotis* is not a species row).
- **모란앵무:** 「모란-앵무」 describes multiple colour forms. The only verified Korean↔학명 link is 붉은모란앵무 = *Agapornis fischeri*. No source ties 모란앵무 to *A. roseicollis* (the brief's example), so it was not mapped as its own entity. *A. fischeri* appears only as an 앵무새 candidate.
- **양무** (서울대공원 "회색앵무(양무)"): the page's 학명 field is misspelled ("Fsittacus erihacus"), and the dictionary's 잉꼬 sense excludes *Psittacus*. Deferred until a clean source is found.
- **Parrot breadth:** the zoo also lists 금강앵무(매커우), 큰유황앵무(황관앵무), 오색앵무 and others. They could be added to 앵무새 later from their idx pages; not added now to keep the subset bounded to common pets.
- **Owls 칡부엉이 / 솔부엉이:** no institutional Korean↔학명 source was verified; an NIBR red-list page fetched without content. 솔부엉이 also has a *Ninox scutulata*/*japonica* split risk.
- **긴발톱할미새, 쇠딱따구리, 까막딱따구리, 크낙새, 중백로:**
  - no verified source for 긴발톱할미새, 까막딱따구리 and 크낙새;
  - the scientific names may have changed for 쇠딱따구리 (*Dendrocopos kizuki* in the census; not checked in AviList). 중백로 is root-owned: pinned AviList has *Ardea intermedia*, not *Egretta intermedia*.
- **두견 aliases** (두견새, 귀촉도, 불여귀, 자규 …): 「두견」 lists them, but no verified Korean↔학명 source for 두견이 (*Cuculus poliocephalus*) was obtained.
- **공작/공작새:** owned by root (AKS + NIAS).
- **기러기:** 「기러기」 lists 쇠기러기, 큰기러기, 회색기러기.
  - 큰기러기 (*Anser fabalis* in the census) maps poorly onto the bean-goose split (pinned AviList has both *A. fabalis* and *A. serrirostris*).
  - 회색기러기 has no source.
  - A single-candidate 기러기 group would narrow misleadingly, so it was deferred. 거위 is out of scope (owned by another task).
- **오리:** a group too broad to bound meaningfully; 집오리 already exists.
- **거위 / 칠면조 / 메추리:** out of scope per the brief (major domestic animals owned elsewhere).

## 검증과 한계

18개 고유 대상 모두 고정 AviList 2025b 원본에서 정확히 한 개의 species 행이다. 실제 NAS의 Wikidata 유래 한국어 이름과 충돌 여부 및 활성 분류판은 연결 복구 후 검증해야 한다. 단일 종의 정규 한국어 이름을 바꾸는 작업은 하지 않았다. 일반 학명 조회와 직접 profile·lineage 조회는 기존 종 조회 계약을 유지한다.
