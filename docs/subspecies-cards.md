# 그래프 검색을 통한 아종·통칭 카드

이 작업은 아종·통칭 조회와 카드 연결에 관한 별도 범위다. RG-401~RG-404·RG-502를 RG-201의 하위 작업으로 간주하지 않는다.

## 조회 흐름

- 통칭 → 승인된 `BirdNameUsage -[:NAME_RELATION]-> Taxon` 관계 조회 → 고유 대상이 하나면 연결된 종의 설명·카드 버튼 자동 표시. 여러 대상이면 사용자가 선택한다.
- 종 → 설명창의 **이 종의 아종 살펴보기** → 승인된 `species -[:PARENT_OF]-> subspecies` 관계 → 아종 선택 → 별도 아종 카드.
- 아종 학명 질문 → 활성 분류판의 정확한 아종 조회 → 아종 설명·카드.
- 아종 설명에서 소속 종 자료를 조회할 수 있다. 가축형·품종은 자동으로 아종으로 취급하지 않고 관련 야생종을 구분한다.

`GET /v1/taxa/subspecies?name=청둥오리`는 `parent_species`, `subspecies`, `concept_set_id`, `taxonomy_release`, 출처와 `has_more`를 반환한다. 최대 200개를 표시하며 한도를 넘으면 안내한다. `GET /v1/taxa/profile`은 종과 아종을 지원한다. 학명의 빈칸 개수로 관계를 추정하지 않는다. 실제 Neo4j 대상·부모 관계를 검증한다.

## 아종 자료 정책

기존 카드 디자인을 재사용하며 **아종**, 소속 종, 확인된 아종 설명을 표시한다. 아종 직접 형질은 `traits`, 부모 종 참고 형질은 `reference_traits`에 분리한다. 참고 형질에는 `reference_scope=species`와 `reference_taxon` 및 기존 개별 출처가 포함된다. 카드 뒷면 **종 수준 참고 정보**에서 펼치며 아종의 체중·먹이·서식 환경으로 사용하지 않는다.

사진은 정확한 아종 학명과 Wikidata 아종 rank [Q68947](https://www.wikidata.org/wiki/Q68947) 매핑을 확인하고 기존 개별 파일 라이선스 정책을 적용한다. 부모 종 사진으로 대체하지 않는다. 아종 보전 등급은 현재 별도 검증 자료가 없어 미확인·중립 색상으로 표시한다. 부모 종 등급을 상속하지 않는다.

현재 NAS TEST 그래프에는 n8n 분류 수집으로 적재된 아종 19,879개와 부모 관계가 있다. 이번 작업은 데이터를 재수집하거나 DB를 변경하지 않고 기존 그래프를 조회한다. [AviList v2025b](https://www.avilist.org/checklist/v2025b/)의 분류판·출처를 유지한다.

모든 아종은 활성 그래프의 원자료 `range_text`를 공통 조회 함수에서 읽어 분포와 출처를 표시한다. AviList v2025b의 19,879개 아종에는 모두 분포문이 있으나 표준 영어 이름 열은 비어 있다. 별도 이름은 출처를 확인한 참고 JSON을 통해 보완하며, 정확한 AviList ID와 학명이 일치할 때만 사용한다. 한국어 이름을 추측하거나 영어 이름을 임의 번역하지 않는다.

표시 우선순위는 확인된 한국어 통칭 → 출처 있는 영어 통칭 → 부모 종 일반명과 분포 설명용 캡션이다. `display_label`은 정식 통칭 필드와 분리하며, 이름이 확인되지 않은 경우에만 사용한다. 목록과 선택 프로필이 같은 표시 함수를 사용한다. 조회는 계속 정확한 학명으로 수행하고, 종·아종 ID·rank·활성 분류판 일치를 검증한다.

RG-503에서 종별 분포 예외를 공통 검토 자료로 교체했다. ID·학명·분류판·개념집합·원문 SHA-256이 일치하는 검토 레코드만 한국어 설명과 캡션으로 표시하며, 미검토·충돌·번역 실패·원문 변경은 영어 원문으로 표시한다. 원문과 출처는 유지한다. 2026-10-07 로컬 적용 범위는 1,109개이며 18,770개는 미검토이다. 한국어 검토 주체는 Codex이며 독립된 사람의 검토를 뜻하지 않는다. NAS TEST 배포 여부는 RG-503 기록을 따른다. 분포 문구는 깃털·형태의 구별 특징이나 계통 거리를 뜻하지 않는다. 목록의 긴 분포는 세 줄로 제한하고 전체 원문·학명·이름/분포 각각의 근거는 접힌 상세에서 확인한다. 카드 앞면은 분류 출처와 다른 안전한 설명 출처도 표시한다.

분류와 형질은 기존 n8n 파이프라인으로 수집된 자료를 사용한다. 이번 이름 자료 보완은 `scripts/build_subspecies_names.py`와 고정 참고 파일, 전체 분포 적용 감사는 `scripts/audit_subspecies_display.py`를 사용한다. 새로운 n8n 워크플로 실행이나 활성 DB 재적재는 이 표시 개선에 필요하지 않다.

## 검증 및 배포

전체 아종 공통 표시 개선과 실제 DB/API 검증, 통과·실패·건너뛰기 및 NAS TEST 배포 결과는 [상세 작업 기록](verification/2026-10-06-global-subspecies-names-and-ranges.md)에 기록한다. 이전 아종 탐색 기능 도입 결과는 [2026-10-03 기록](verification/2026-10-03-subspecies-common-name-cards.md)에 보존되어 있다.

## 한국어 분포 자료 갱신 (RG-503)

`data/review/subspecies-range-ko.json`에 완전한 원문 표현별 한국어 설명·캡션과 검토 상태를 기록한다. 후보를 추가했다는 이유만으로 검토 완료로 취급하지 않으며 `status: reviewed`와 원문 대조가 필요하다. `scripts/build_subspecies_ranges.py`에 공식 고정 스냅샷을 주면 ID별 런타임 자료·전수 처리 원장·집계를 생성한다. `--check`는 런타임 자료가 바이트 단위로 재현되는지 확인한다. 검토된 번역은 정식 국명 필드에 넣지 않는다.

실제 검증 범위, 미검토 수와 배포 상태는 [RG-503 상세 작업 기록](verification/2026-10-07-RG010-korean-subspecies-ranges.md)에 기록한다.
