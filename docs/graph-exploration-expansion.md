# 그래프 관계 탐색 후속 작업 (RG-003)

RG-003은 상위 작업이며 RG-004~RG-009의 완료 기준을 각각 검증한다. 이 문서는 RG-004 이후의 변경과 검증 범위를 기록한다.

## RG-005 — 비교 결과 별도 말풍선

같은 속·과의 후보에서 비교하기를 누르면 기존 설명을 유지한 채 새 답변 말풍선을 추가한다. 양쪽 종의 이름·자료가 있는 특성·출처·분류판·카드 버튼을 표시한다. 같은 후보의 중복 요청은 진행 중에 막고, 이후에는 다시 비교할 수 있다. 실패 후 재시도와 대화 지우기 이후의 늦은 응답을 처리한다.

## RG-006 — 활동 시간의 잘못된 단정 수정

해오라기(Nycticorax nycticorax)의 EltonTraits 원자료는 `Nocturnal=0`이며, 기존 API는 이를 `False`, 화면은 야행성 **아니요**로 표시했다. 값이 없어서 생긴 오류가 아니라 원자료의 이진 분류와 자세한 종 설명 사이의 차이를 제대로 표현하지 못한 문제다. 데이터셋 작성자의 코딩 의도나 모든 0의 생물학적 의미는 추정하지 않는다.

[Cornell Life History](https://www.allaboutbirds.org/guide/Black-crowned_Night_Heron/lifehistory)의 검토 근거로 활동 시간을 **주로 저녁부터 이른 아침에 먹이를 찾으며, 번식기에는 낮에도 활동합니다**라고 설명한다. 원자료의 0을 임의로 1로 덮어쓰지 않는다. `reviewed_activity.py`에 검토 ID·날짜·출처·요약을 기록하고 고정 분류판 v2025b의 정확한 학명에만 적용한다. `activity_pattern` 형질과 생활·먹이 설명에 검토 요약을 표시하며 원래 야행성 형질은 `source_claims`로 보존한다.

다른 종의 `nocturnal=False`도 **원자료 분류값 0 · 야간 활동이 없다고 단정할 수 없음**으로 표시한다. 실제 boolean 값을 결측으로 바꾸거나 다른 종의 활동 시간을 추정하지 않는다. 원자료 및 활성 DB 기록은 수정하지 않았다.

[원인 조사](research/rg006-nocturnal-diagnosis.md)에서 확인된 사실과 추론의 한계를 구분한다.

## RG-007 — 남은 영어 생태 용어

NAS TEST 활성 형질 자료의 모든 범주값과 고정 AVONET 원본을 대조했다. 원본 SHA-256은 `eb645e83dddb40f1654a3e8d721998dbca76eff540231b7b809267c1e96f8d3e`이다.

| 원본 먹이 생태 코드 | 한국어 표시 |
|---|---|
| Aquatic predator | 수생동물 포식 |
| Vertivore | 척추동물 섭식 |
| Invertivore | 무척추동물 섭식 |
| Scavenger | 사체 섭식 |
| Frugivore | 열매 섭식 |
| Nectarivore | 꽃꿀 섭식 |
| Granivore | 씨앗 섭식 |
| Herbivore aquatic | 수생 초식 |
| Herbivore terrestrial | 육상 초식 |
| Omnivore | 잡식 |

기존 서식지·생활 방식·먹이 유형 번역도 유지한다. 먹이 활동 위치의 실제 코드 `mid_high`를 중상층으로 표시한다. 원본 `value`는 보존한다. 등록되지 않은 범주는 **번역 확인 필요**, `NA` 등 결측 코드는 **자료 없음**, 알려지지 않은 구성 항목은 **미분류 항목**으로 표시한다. 구성비는 유한한 양의 숫자만 표시하며 0과 결측은 음식 존재 근거로 사용하지 않는다.

## RG-008 — 출처에 따른 다중 먹이 아이콘

서식지 문양과 함께 출처가 있는 먹이 정보를 별도 아이콘으로 표시한다. 양의 구성비가 확인된 먹이 항목마다 아이콘을 추가하고, 온혈·변온·기타 척추동물은 척추동물 아이콘으로 묶는다. 물고기는 따로 표시하며 상위 척추동물 묶음과 구분한다. 동일 자료를 중복 계산하거나 다른 자료의 비율을 더하지 않는다.

먹이 구성 정보가 없으면 먹이 유형·먹이 생태 범주의 아이콘으로 안내한다. `VertFishScav` 같은 묶음 범주를 세 항목 모두 존재한다는 뜻으로 풀지 않는다. `Aquatic predator`만으로 물고기 식성을 추정하지 않는다. 0·결측·미등록 항목 및 출처가 없는 정보에는 임의 아이콘을 붙이지 않는다. 카드 뒷면에서 아이콘 기준과 출처를 펼칠 수 있다.

## RG-009 — 사용 가능한 사진이 없는 조류

설명·카드·뒤집기를 사진 유무와 분리한다. 사진 대신 다른 종의 사진을 추정해 넣지 않는다. 확인된 사진은 개별 파일의 출처·저작자·라이선스를 함께 유지한다.

프로젝트는 개별 파일 메타데이터에서 CC0·공공영역 또는 허용 CC BY/CC BY-SA 2.0·2.5·3.0·4.0을 확인한다. 제한 조건·불명확한 라이선스·필수 출처 정보가 없는 파일은 사용하지 않는다. 이는 프로젝트의 수집 정책이며 Commons 전체의 모든 파일을 무조건 허용하는 의미가 아니다.

공식 근거: [Commons 재사용 안내](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

API의 기존 `images` 배열은 유지하고 `photo_availability`에 상태와 한국어 안내를 추가한다.

| 상태 | 의미 |
|---|---|
| available | 확인된 사진 있음 |
| no_licensed_photo | 검토 과정에서 사용 조건이 확인된 대표 사진 없음 |
| unconfirmed_taxon | 사진 제공 자료에서 정확한 종 연결을 확인하지 못함 |
| ambiguous_taxon | 여러 종 식별자가 있어 사진을 선택하지 않음 |
| provider_unavailable | 사진 제공처 조회 실패 |

브라우저의 사진 파일 로딩 실패는 제공처 메타데이터 조회 실패와 별도로 처리한다. 개별 사진 출처를 보존하며 실패 안내와 재시도를 제공한다.
